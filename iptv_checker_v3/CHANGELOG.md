# Changelog

本项目变更记录。

## [Unreleased] - 2026-07-12

- 修复滚动 HLS 总取最旧切片导致的误杀；改为验证最多三个最新切片并递归处理主播放列表。
- 修复仅凭切片 HTTP 200、裸流长度大于 100 字节造成的 HTML/JSON/文本假阳性。
- 增加媒体魔法字节、实际切片内容与选中变体分辨率校验；停更响应头降级为提示，不再覆盖有效切片证据。
- `Unknown/Unknown` 不再作为 24 小时死流缓存；ffprobe 超时、缺失等不确定结果不再覆盖强存活证据。
- ffprobe 超时后显式终止并回收子进程，直探切片使用较短上限且保留“切片 -> 原链 -> 文本”三层回退。
- Windows 启用 ffprobe 时切换到 Proactor 事件循环，修复 Selector 下异步子进程恒定失败。
- 缓存首选路径修正为仓库 `config/probe_cache.json`，兼容读取旧模块目录缓存。
- 修复媒体 MIME 被误当成强证据、`no_video` 被文本分辨率覆盖、ffprobe 缺失时正缓存失效，以及测试覆盖生产日志的问题。
- 新增 20 个本地异步回归场景。
